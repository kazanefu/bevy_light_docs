# はじめに

## この資料について

この資料はGammaのBevy初心者向けBevy入門ガイドです。<br>
「Bevyなんか一回も触ったことない」という初心者でも安心してBevyを始められるよう、基本的なところからUnityの使い方を解説し、簡単なゲームを作れるところまでリードしていきます。(Bevy公式ドキュメント[https://bevy.org/](https://bevy.org/))

![](./images/first_screen_shot.png)<br>

↑こんな感じの帰宅ゲームを作っていきます！

まずは自分のパソコンの中にBevyの作品を入れるフォルダを作成し、そこに光の資料のGoogleドライブにあるzipファイルを展開します。<br>
エクスプローラーを開き、PC＞ローカルディスク（C:）の中に「BevyWorks」フォルダを作成しましょう。（慣れている方はお好みでどうぞ。）<br>
光の資料のドライブにある「bevy_sample_game.zip」を右クリック、「すべて展開」を選択し、参照ボタンから先ほど作成した「BevyWorks」フォルダを選択して.zipファイルを展開します。<br>

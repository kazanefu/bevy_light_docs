# ゲームを作ってみよう!

まずは、[はじめに](./introduction.md)でダウンロードしたサンプルゲームのディレクトリをテキストエディタで開いたり、ターミナルでビルド&実行してみましょう。<br>
CLI(Command Line Interface)での操作に慣れていない人もいるかと思いますが、使えると便利ですし、この資料では簡単なコマンドしか使わないので、ぜひ覚えていきましょう。<br>
```bash
# ディレクトリを開く
# ここでは、Cドライブの直下にBevyWorksというフォルダを作成し、その中にゲームのサンプルを展開したと仮定しています。
# ゲームのzipファイルを展開した場所は人によって違うと思うので、適宜読み替えてください。
cd BevyWorks/bevy_sample_game
# VSCodeで開く
code .
# ビルド&実行する
cargo run
```
> 一応説明しておくと、`cargo run`は、Rustのビルドツール兼パッケージマネージャーであるCargoに「ビルドして実行してね」とお願いするコマンドです。
ビルドだけする場合は`cargo build`を使います。
リリースビルドをする場合は`cargo build --release`のように`--release`とつけます。

矢印キーor WASDキーでキャラクターを動かすことができます。<br>

試しに、プレイヤーの移動スピードや敵の移動スピードを変えてみましょう。<br>

`src/player/mod.rs`の中にある
```rust
impl Default for Player {
    fn default() -> Self {
        // デフォルトの移動速度を設定
        Self { speed: 200.0 }
    }
}
```
という箇所のspeedの値を変えると、プレイヤーの移動スピードが変わります。<br>

似たような感じでenemyの移動スピードも変えられます。<br>

`src/enemy.rs`の中にenemyのspeedの値を変える箇所があるので、探して変えてみましょう。<br>

値を変えたら、再度`cargo run`でビルド&実行して、ゲーム内での挙動を確認してみましょう。

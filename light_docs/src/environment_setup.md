# 環境構築

続いてゲーム作成に必要なRustの開発環境一式とプログラムを書くのに必要なテキストエディタであるVSCodeをダウンロード、インストールしていきます。<br>
概要のみ記載しているので、Rustの公式ドキュメントを参考にしたり、VSCodeは既に入れている人に教えてもらいながら進めましょう。<br>

## rustupをインストールする

まずは、[Rustの日本語公式ドキュメント(the book)](https://doc.rust-jp.rs/book-ja/ch01-01-installation.html)に従って、Rustのバージョンと関連するツールを管理する「rustup」をインストールします。<br>
軽く公式ドキュメントに書いてあることをまとめると、以下の手順でインストールできます。
1. [https://rust-lang.org/tools/install/](https://rust-lang.org/tools/install/)に行き、DOWNLOAD RUSTUP-INIT.EXE(X64)をクリックしてダウンロードします。
2. ダウンロードした「rustup-init.exe」を実行します。
3. インストールの途中で、Visual StudioのC++ビルドツールをインストールするか聞かれるので、まだインストールしていない場合はインストールしてください。
  - 「C++によるデスクトップ開発」("Desktop Development with C++")
  - Windows 10または11のSDK
  - 英語の言語パック(English language pack)コンポーネント
4. インストールできたかを確認する
  - `rustc --version`と`cargo --version`をターミナルで実行し、バージョンが表示されればOKです。一応簡単にそれぞれ説明すると、`rustc`はRustのコンパイラ、`cargo`はRustのビルドツール兼パッケージマネージャーです。

## VSCodeをインストールする

BevyではRustという言語でプログラムを書いていくことになります。<br>
このガイドではVSCodeと呼ばれるテキストエディタ(テキストファイルを編集するソフト)を用いることとします。(任意のエディタを使っても構いません。なんならメモ帳でも(おすすめはしない))<br>
公式サイト（https://code.visualstudio.com/download）にアクセスしてダウンロード、インストーラを起動して指示に従ってインストールします。基本的にデフォルトの設定で問題ないと思いますが、「PATHへの追加」の項目はONにしておきましょう。<br>
VSCodeを起動し、拡張機能の検索欄に「rustanalyzer」と入力し、RustAnalyzerをインストールします。<br>

次のページからゲーム制作が始まります。<br>
途中で様々なエラーが表示されるかと思いますが、この資料のおまけページにガイドで出そうなエラー集のページを設けているので、そちらを参考にしてみたり、rustのコンパイラはエラーメッセージが非常に親切なので、ちゃんと読んでみると解決できることが多いです。また、`rustc --explain <エラー番号>`でエラーの詳細を確認できます。<br>

# 敵を作ってみよう～自力でいろいろ作ってみよう

ここまで来れば、今までの知識だけで敵を作成し、ゲームオーバーまで作れます。やってみよう！どうぞ！<br>
...というのは流石に放任過ぎるので、方向性だけ海底置きますので参考に。<br>
- 継続的な敵の出現は難しいので作らない想定
- プレイヤー同様に敵のコンポーネントを作成し、そのコンポーネントを対象とした移動のシステムを作る
- 移動は一定区間を往復するようにする
- プレイヤーとゴールの衝突判定のように、プレイヤーと敵の衝突判定を作る
- 敵と衝突したときにEndingMessage::GameOverを送信するようにする
- わからないところは検索してみたり筆者に聞いてみよう。

余力があったら自分なりのステージをいくつか作成してください。敵以外にも色んなものを自分で作ってみよう。すべては君のアイデア次第！用語だけは上げておくので、気になるものは自分で調べてみたり、筆者に質問したりしてみよう！
- 敵を途中で新たにスポーンしてみたりとか
- 制限時間とか移動を阻む壁とか
- マリオみたいなジャンプを作ったり
- 反発係数を上げてみたり
- 速度を直接変えるのではなく、力を加えて移動させてみたり
- スペースキーを押しながら移動でダッシュできるようにしたり
- イラストを自分で用意してアニメーションさせてみたり
- プレイヤーの攻撃手段と敵のHPをつくってみたり
- パーティクルを使ったエフェクトを作ってみたり
- 背景を変えてみたり
- スマホで操作できるようにしてみたり
- BGMを追加してみたり
